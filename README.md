# 🎄 크리스마스 광장 — 엘프의 겨울 마을

눈 내리는 3D 웹 광장에서 엘프가 되어 함께 걸어요. 브라우저만 있으면 되고, 설치·로그인 없이
**같은 방 코드를 입력한 사람끼리 최대 10명이 실시간으로** 만납니다.

- **접속**: https://dltpffldk.github.io/christmas-metaverse/
- **초대**: `?room=` 뒤에 방 코드를 붙이면 그 방으로 바로 들어갑니다.
  예) `https://dltpffldk.github.io/christmas-metaverse/?room=main`

| 📝 소원 쪽지 | 라운지 서쪽 벽 게시판 앞에서 소원을 적어 걸면 쪽지가 게시판에 남고, 같은 방 친구에게도 보입니다 (이 방에 최대 8장 보관) |
| 그림책 연출 | 야외에서 걸으면 눈 위에 발자국이 잠깐 남았다 사라지고, 몇 초마다 입김이 피어오릅니다. 캐롤 BGM을 켜면 모닥불·벽난로에 가까울수록 장작 타닥거리는 소리(Web Audio 합성)가 커집니다 |

## 조작

- **PC**: `W A S D` / 방향키 이동, `Shift` 달리기, 마우스 드래그 시점, 휠 줌
- **이동 속도**: 걷기 4.8 m/s · 달리기 7.8 m/s (3차 업그레이드에서 약 1.45배 상향, 발걸음 애니메이션도 함께 빨라짐)
- **모바일**: 좌측 조이스틱 이동, 화면 드래그 시점, 두 손가락 핀치 줌
- **앉기**: 모닥불 반경 4.8m 안에서 우측 하단 `🪑 앉기` 버튼 또는 `E` / `F` 키.
  앉은 채로 이동 키를 누르거나 `🧍 일어서기` 를 누르면 자연스럽게 일어납니다.

## 실시간 연결 방식

정적 호스팅(GitHub Pages)에는 서버가 없으므로, 공개 MQTT 브로커의 WebSocket 포트를
릴레이로 씁니다. 별도 서버도, 유료 API 키도 필요 없습니다.

- 브로커: `wss://broker.emqx.io:8084/mqtt` (1순위) → `wss://broker.hivemq.com:8884/mqtt` (백업)
- 토픽: `eyun/xmas-plaza/v1/{room}/s/{client}` (위치·회전·걷기·앉기 자세·눈사람 변신 `tf`·마시멜로 굽기 진행 `rs`), `.../e/{client}` (입장·채팅·리액션·소원 쪽지), `.../e/tree` (트리 장식 개수·점등 상태, retained)
- 입장·퇴장은 retained 메시지 + LWT(유언)라서, 늦게 들어온 사람도 현재 인원을 바로 알고
  비정상 종료도 자동으로 정리됩니다.
- 브로커에 닿지 않으면 조용히 **혼자 둘러보기(데모)** 모드로 전환됩니다.

## 렌더링

- Three.js `r160` + `EffectComposer` 체인: `RenderPass → UnrealBloomPass(은은) → Grade(채도·색온도·비네트·디더) → OutputPass`.
  톤매핑(ACES)과 sRGB 변환은 `OutputPass`에서 한 번만 일어납니다.
- 조명은 키(따뜻한 태양, 그림자 담당)+차가운 하늘광+림 라이트+프랙티컬(랜턴·트리 전구) 스택,
  IBL은 PMREM 환경맵으로 금속·눈의 하이라이트를 살립니다.
- 캐릭터는 프레넬 림(셰이더 주입)과 발밑 접지 블롭으로 배경에서 분리·접지됩니다.
- 품질은 3단계 자동: 프레임이 계속 28fps 아래면 블룸 세기·픽셀비율을 내리고,
  마지막 단계에서는 포스트프로세싱을 끄고 직접 렌더로 폴백합니다(모바일은 시작부터 낮은 세기).
- 마을·모닥불의 정적 지오메트리는 재질별로 하나의 `BufferGeometry` 로 병합해 드로우콜을 묶고
  (건물 10채 + 소품 100여 개 → 재질 수만큼), 애니메이션이 필요한 불꽃·불씨·연기·불빛만 개별 오브젝트로 둡니다.
- 미리보기: `preview.png`(PC) · `preview-mobile.png`(모바일) · `preview-lobby.png`(입장 화면)
  · `outputs/xmas-village/`(마을·모닥불·앉기 검증 스크린샷)
